# X Joiner

单文件网页图片拼接工具：把多张图片按顺序拼成一张长图。纯前端，打开 `index.html` 即用；图片只在本地浏览器处理，不上传。

## 用法

1. 用浏览器打开 `index.html`（双击即可，无需起服务器）。
2. 左侧「添加图片」：点击选择 / 拖拽文件 / `Ctrl+V` 粘贴，支持多图一次加入；另有「从剪贴板粘贴」按钮。
3. 在「排序」列表拖拽调整顺序；✕ 删除单张，「清空」移除全部；每张显示文件名与原始尺寸。
4. 「设置」：拼接方向（垂直/水平）、间距（0–100px）、背景色，改动实时重新生成预览。
5. 右侧预览满意后，「下载图片」保存为 `x-joiner-<时间戳>.png`，或「复制结果」粘贴到别处。

## 特性

- 零依赖单文件：一个 `index.html`，无构建、无后端。
- 四种图片添加方式：点选、拖拽、快捷键粘贴、剪贴板读取。
- 拖拽排序，所见即所得；缩略图列表带文件名与尺寸。
- 垂直拼接按最大宽度、水平拼接按最大高度定画布；尺寸不一的图片在交叉方向上居中对齐。
- 间距、背景色可调，所改即所得。
- 一键下载 PNG / 一键复制到剪贴板。
- 隐私：图片经 FileReader 转 dataURL 在本地处理，不经过任何服务器。
